A custom Shopify app that reads minX tags from products and enforces minimum order quantities.
Tags must follow the pattern minX, where X is a positive integer.
Tag MOQ Extracted
min4 4
min8 8
min12 12
min100 100
If a product has multiple minX tags, the highest value is used as the product's MOQ.
Tags:

min4   min12

Extracted MOQ: 12
1. Product tags The app reads the tags assigned to each Shopify product. 2. MOQ detection Tags matching minX are converted into numeric values. 3. Highest value When several valid tags exist, the highest number becomes the MOQ. 4. Enforcement The minimum quantity is enforced when the customer attempts to proceed with the order.
MOQ is determined automatically from product tags.
